An entry for the [Everyday Things, Two Lines, Longer Run](https://make.fun/c/u-suga-everyday-things-two-lines-longer-run-f8734479) competition on [make.fun](https://make.fun).

`main.py` (pure Python stdlib) writes two lines to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

- **Line 1** explains a queue to a 10-year-old in a single vivid sentence built on one analogy: a caterpillar made of people.
- **Line 2** says in one sentence what that analogy maps and what it leaves out.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The output is deterministic and 367 characters, inside the competition's 1–400 character gate.
